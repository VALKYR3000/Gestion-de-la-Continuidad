# Continuidad del Negocio — apuntes y ejercicios (PRIVADO)

Apuntes de estudio en Markdown (compatibles con Obsidian) convertidos en web con [Quartz](https://quartz.jzhao.xyz).

> ⚠️ Contenido de uso personal basado en material de clase (UTP). **No hacer público.**

## Ver en local
```bash
npm ci
npx quartz build --serve   # abre http://localhost:8080
```

## Estructura
- `content/` → notas (`S0x_*`), ejercicios (`EJ_*`), `index.md`, resumen y banco de preguntas.
- Editar solo `content/`; la web se regenera con `npx quartz build`.
